#### \# Expense Tracker: Specification

#### \## Problem

#### Students lose track of daily spending.

#### \## Users

#### One person using a command-line app.

#### \## Must-have features

#### 1\. Add an expense (amount, category, date, note)

#### 2\. List all expenses

#### 3\. Edit and delete an expense

#### 4\. Monthly total, and total per category

#### 5\. Export to CSV

#### \## Data (SQLite table: expenses)

#### id, amount, category, date, note

#### \## Rules

#### \- Amount must be a positive number

#### \- Date format: YYYY-MM-DD

#### \## Out of scope (for now)

#### Login, web UI, charts

#### \## Done when

#### All 5 features work, with tests and a README
